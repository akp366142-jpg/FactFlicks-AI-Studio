# Captions and Accessibility

Create concise, accurately timed captions from the approved narration. Use readable contrast, sensible line breaks, and mobile-safe placement. Preserve names and technical terms. Avoid covering important visual information. Provide a transcript and meaningful visual descriptions where useful; do not rely on color alone.

## Output
Return structured, concise results that the next workflow stage can use. State assumptions and unresolved checks explicitly.
