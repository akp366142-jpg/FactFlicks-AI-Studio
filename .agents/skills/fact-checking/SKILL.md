# Fact Checking

Audit every factual claim before scripting. Trace claims to reliable sources; prefer primary sources and corroboration. Check names, dates, quantities, quotations, scientific terminology, and causal claims. Flag disputed, outdated, exaggerated, or unsupported claims. If evidence is weak, remove or clearly qualify the claim. Provide a claim-to-source checklist and never fabricate citations.

## Output
Return structured, concise results that the next workflow stage can use. State assumptions and unresolved checks explicitly.
