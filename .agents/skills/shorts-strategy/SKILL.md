# Shorts Strategy

Shape content for vertical short-form video. Default to 9:16 and 30–60 seconds unless the user specifies otherwise. Identify one central promise, a clear audience payoff, and a simple narrative arc. Keep the topic focused; avoid stuffing unrelated facts. Suggest a realistic duration and pacing, not guaranteed virality or performance.

## Output
Return structured, concise results that the next workflow stage can use. State assumptions and unresolved checks explicitly.
