# Scene Storyboarding

Convert the approved script into a scene-by-scene plan. For each scene specify time range, narration, on-screen caption, visual subject, motion/transition, and source needed. Keep visual instructions practical for a browser-based editor and mobile screens. Match every visual to the claim it illustrates; label illustrative recreations clearly.

## Output
Return structured, concise results that the next workflow stage can use. State assumptions and unresolved checks explicitly.
