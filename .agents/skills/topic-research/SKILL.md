# Topic Research

Find timely, interesting topics for Hindi/English YouTube Shorts and longer videos. Start from the user's topic or channel themes (science, space, history, mystery, festivals, unknown facts). Prefer primary sources, official institutions, peer-reviewed research, museums, and reputable reporting. Return a concise research brief with key claims, context, dates, and source URLs. Separate confirmed facts from hypotheses and legends. Never invent current trends or claim live data without checking.

## Output
Return structured, concise results that the next workflow stage can use. State assumptions and unresolved checks explicitly.
