# Short Video Editing

Plan a clean vertical edit with readable safe-area captions, consistent typography, purposeful cuts, subtle motion, balanced narration/music, and a clear ending. Keep background music below speech and respect licensing. Validate aspect ratio, duration, audio presence, and output format. Be transparent about browser memory and export limitations.

## Output
Return structured, concise results that the next workflow stage can use. State assumptions and unresolved checks explicitly.
