# Visual Asset Research and Licensing

Find relevant photographs and footage from sources whose reuse terms can be checked. Record the original file page, creator, license name, license URL, and required attribution. Prefer public-domain or permissively licensed material. Do not assume a search thumbnail is reusable. Reject assets with unclear provenance and preserve credits in the project output.

## Output
Return structured, concise results that the next workflow stage can use. State assumptions and unresolved checks explicitly.
