# Voiceover Direction

Prepare narration for Hindi or English text-to-speech. Normalize punctuation, numbers, abbreviations, and pronunciation-sensitive names without changing meaning. Recommend a suitable voice, pace, and emphasis based on the requested tone. Keep narration within provider limits and report when text must be shortened. Never claim audio was generated unless the provider call succeeded.

## Output
Return structured, concise results that the next workflow stage can use. State assumptions and unresolved checks explicitly.
