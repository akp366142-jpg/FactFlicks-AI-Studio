# FactFlicks AI Studio

A responsive React + Vite starter for a Hindi/English video creation workspace.

## Current stage — Phase 1
- Responsive creator dashboard
- Topic, style, language, duration and voice selections
- Local script/storyboard draft generation
- Copy script action

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Important
This first version creates a **draft script only**. It does not yet research facts, generate AI audio or images, or render MP4 files. Those require additional services/models and will be added in later phases. Free services have usage limits; unlimited free generation and hosting cannot be promised.

## Planned next phases
1. Reliable fact research and source links
2. Text-to-speech with Hindi/English voice choices
3. Visual generation / copyright-safe stock media
4. Subtitle timing, editing and MP4 rendering
5. Deployment and mobile testing
